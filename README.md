# Arena Brothers Beach Tennis

Site institucional da Arena Brothers Beach Tennis, em Marabá — PA.

## Requisitos

- Node.js 22.13 ou superior
- npm

## Executar localmente

```bash
npm ci
npm run dev
```

Depois, acesse `http://localhost:5173`.

## Gerar a versão de produção

```bash
npm run build
npm run start
```

## Conteúdo principal

- Página responsiva para desktop e celular
- Identidade visual oficial da Arena Brothers
- Contato e agendamento pelo WhatsApp
- Localização no Google Maps
- Seção de eventos
- Feed visual de Instagram

O código pode ser versionado normalmente em um repositório GitHub. Pastas geradas, dependências instaladas e configurações locais já estão ignoradas pelo `.gitignore`.
